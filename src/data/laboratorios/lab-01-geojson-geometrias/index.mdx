fundamentoTeorico: "El estándar GeoJSON (RFC 7946) codifica objetos geográficos mediante la especificación Simple Features de la OGC. Define tipos primarios (Point, LineString, Polygon) organizados en estructuras Feature y FeatureCollection con coordenadas [Longitud, Latitud]."

    descripcion: "Identificar la dimensionalidad de las entidades: Puntos (0D) para colegios, LineStrings (1D) para vías de acceso y Polígonos (2D) para zonas prediales."

    fase: "REPRESENTACIÓN"
    titulo: "Definición del Esquema GeoJSON"
    descripcion: "Estructurar la colección mediante 'type': 'FeatureCollection' y un arreglo 'features' conteniendo la geometría y las propiedades alfanuméricas."
  - paso: 3
    fase: "ALGORITMO"
    titulo: "Regla de Cierre de Polígonos"
    descripcion: "Para geometrías de tipo Polygon, el primer vértice y el último vértice del anillo exterior deben ser exactamente idénticos para garantizar una superficie cerrada."
  - paso: 4
    fase: "CÓDIGO"
    titulo: "Construcción de la FeatureCollection"
    descripcion: "Definición del documento GeoJSON con un punto (Colegio) y un polígono (Predio)."
    lenguaje: "json"
    codigo: |
      {
        "type": "FeatureCollection",
        "features": [
          {
            "type": "Feature",
            "geometry": {
              "type": "Point",

            },
            "properties": {
              "id": "SCH-001",
              "nombre": "Institución Educativa Central",

          {
            "type": "Feature",

preguntasAnalisis:
  - pregunta: "¿Por qué el estándar GeoJSON especifica el orden [Longitud, Latitud] en lugar del tradicional [Latitud, Longitud] de la cartografía?"
    orientacion: "En ciencias de la computación y geometría cartesiana bidimensional, el eje X horizontal corresponde a la Longitud y el eje Y vertical a la Latitud."
  - pregunta: "¿Qué sucede si el último par de coordenadas de un Polygon difiere del primero?"
    orientacion: "Los motores de renderizado espacial no podrán calcular el área ni realizar intersecciones topológicas debido a un polígono no cerrado (abierto)."

  titulo: "Reto: Modelar una Cancha Deportiva Interna (Donut Polygon)"
  descripcion: "Modifica el documento GeoJSON para incluir una zona verde interior no construida dentro del predio (un hueco o anillo interior)."
  pistas:
    - "El tipo Polygon acepta un arreglo de anillos: el primer arreglo es el perímetro exterior y los siguientes son agujeros interiores."

  - error: "Inversión de coordenadas [Lat, Lon] ubicando la entidad en el océano o en la Antártida."
    solucion: "Confirma siempre que X (Longitud, en Colombia ~ -75°) vaya primero que Y (Latitud, en Colombia ~ 3° a 11°)."
