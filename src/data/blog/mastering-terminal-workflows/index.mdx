Las bases de datos relacionales tradicionales utilizan índices B-Tree indexando valores en una sola dimensión. Para datos bidimensionales (X, Y), se requiere indexación R-Tree basada en Bounding Boxes (MBR).

## Consultas Espaciales en PostGIS

```sql
SELECT nombre, ST_Distance(geom, ST_MakePoint(-75.567, 6.248)::geography) AS distancia_m
FROM capas_infraestructura
WHERE ST_DWithin(geom, ST_MakePoint(-75.567, 6.248)::geography, 5000);
```

El uso de `USING GIST (geom)` permite resolver consultas espaciales en milisegundos sobre millones de registros.
