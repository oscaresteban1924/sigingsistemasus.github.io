El geoprocesamiento automatizado permite ejecutar pipeline de análisis de datos a escala sobre conjuntos de datos masivos usando bibliotecas como Shapely, GeoPandas y GDAL.

## Pipeline de Análisis con GeoPandas

```python
import geopandas as gpd

gdf_puntos = gpd.read_file("estaciones.geojson")
gdf_barrios = gpd.read_file("barrios.geojson")

puntos_en_barrios = gpd.sjoin(gdf_puntos, gdf_barrios, predicate="intersects")
print(puntos_en_barrios.groupby("nombre_barrio").size())
```

Este código ejecuta una unión espacial (_spatial join_) optimizada mediante estructuras R-Tree internas.
