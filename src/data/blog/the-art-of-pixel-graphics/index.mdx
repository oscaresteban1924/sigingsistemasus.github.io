La interoperabilidad es la capacidad de sistemas heterogéneos para intercambiar y procesar información geográfica sin barreras propietarias.

## Servicios OGC Principales

- **WMS (Web Map Service):** Renderiza y entrega imágenes de mapas (PNG/JPEG).
- **WFS (Web Feature Service):** Entrega geometrías y atributos vectoriales crudos (GeoJSON/GML).
- **WCS (Web Coverage Service):** Entrega capas raster continuas procesables.

Los servidores geoespaciales como GeoServer implementan estos estándares sobre HTTP REST.
