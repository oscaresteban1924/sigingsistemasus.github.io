En la ingeniería de datos geoespaciales, la elección del modelo de datos determina el costo computacional de los algoritmos de consulta y análisis.

## Modelo Vectorial

Representa el espacio mediante geometrías discretas bien definidas (Simple Features Schema de la OGC):

- **Puntos (0D):** Coordenadas (X, Y) aisladas (ej. estaciones de monitoreo).
- **Líneas (1D):** Secuencias ordenadas de vértices (ej. redes viales, tuberías).
- **Polígonos (2D):** Anillos cerrados de coordenadas (ej. predios, municipios).

## Modelo Raster

Representa el espacio como una matriz o cuadrícula continua de celdas (píxeles), donde cada celda almacena un valor atributo (ej. elevación DEM, imágenes satelitales).

La elección entre vector y raster depende del problema computacional: análisis topológico vs geoprocesamiento matricial.
